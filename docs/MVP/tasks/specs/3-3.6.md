# Task 3.6: Lambda: WHISPER_TRANSCRIBE

## 0) Outcome

Lambda function `attic-whisper-transcribe` transcribes audio from videos using OpenAI Whisper API when subtitles are not available from TikTok. Returns empty gracefully for non-video content (no state machine branching required).

## 1) Scope

### In-scope
- [ ] Lambda function that calls OpenAI Whisper API for transcription
- [ ] Extract audio from video files in S3
- [ ] Skip non-video media types (return empty transcript)
- [ ] Skip videos that already have subtitles from SUBTITLE_FETCH
- [ ] Update media_events.subtitle_text and set subtitle_source = 'whisper'
- [ ] Track cost per item in processing_steps ($0.006/minute)
- [ ] Handle long videos (truncate if > 10 min for cost control)

### Out-of-scope / Non-goals
- Local Whisper model (use OpenAI API only for MVP)
- Batch transcription (one video per API call)
- Multiple language detection (assume English)

## 2) System context

### Components touched
- **Lambda function**: `attic-whisper-transcribe`
- **Third party**: OpenAI Whisper API
- **AWS S3**: Read from temp bucket
- **DB tables**: `media_events`, `processing_steps`
- **Step Functions**: Invoked as Map state

### Invariants (must always be true)
- Never transcribe if subtitle_text already exists
- Non-video media types return immediately with empty result
- Cost tracked accurately in processing_steps
- OpenAI API key never logged

### Lambda Output
```python
from pydantic import BaseModel
from uuid import UUID
from typing import Literal

class TranscriptionResult(BaseModel):
    media_event_id: UUID
    status: Literal["transcribed", "skipped", "failed"]
    subtitle_source: Literal["whisper", None] = None
    transcript_length: int | None = None
    duration_transcribed_seconds: int | None = None
    cost_usd: float | None = None
    error_message: str | None = None

class WhisperTranscribeOutput(BaseModel):
    upload_id: UUID
    items_transcribed: int
    items_skipped: int  # Already have subtitles or non-video
    items_failed: int
    total_cost_usd: float
    results: list[TranscriptionResult]
```

## 4) Data model changes

### media_events updates
```sql
UPDATE media_events SET
    subtitle_text = $transcript,
    subtitle_source = 'whisper',
    processing_substate = 'transcribed',
    updated_at = NOW()
WHERE id = $media_event_id
  AND subtitle_text IS NULL;  -- Only update if no existing subtitles
```

### processing_steps insert
```sql
INSERT INTO processing_steps (
    id, media_event_id, step_type, provider, status,
    started_at, finished_at, cost_usd, output_summary
) VALUES (
    $id, $media_event_id, 'WHISPER_TRANSCRIBE', 'openai_whisper',
    $status, $started_at, $finished_at, $cost_usd, $output_summary
)
ON CONFLICT (media_event_id, step_type, attempt) DO UPDATE SET
    status = EXCLUDED.status,
    finished_at = EXCLUDED.finished_at,
    cost_usd = EXCLUDED.cost_usd,
    output_summary = EXCLUDED.output_summary;
```

## 5) Workflow & state machine (if applicable)

### States
- This Lambda IS a state in the pipeline (TranscribeAudio Map state)

### Idempotency strategy
- Check subtitle_text IS NULL before transcribing
- Upsert operations for all database writes
- Same audio file produces same transcription

### Failure modes + user-facing behavior
- **OpenAI rate limit**: Retry with exponential backoff
- **OpenAI API error**: Retry, then mark as failed
- **Non-video media type**: Return immediately with "skipped"
- **Already has subtitles**: Return immediately with "skipped"
- **Video too long**: Truncate to 10 min or skip based on tier
