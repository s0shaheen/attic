# Task 3.5: Lambda: SUBTITLE_FETCH

## 0) Outcome

Lambda function `attic-subtitle-fetch` retrieves subtitles/captions for videos when available from TikTok (via Apify metadata), storing the text in `media_events.subtitle_text`.

## 1) Scope

### In-scope
- [ ] Lambda function that checks for available subtitle URLs from Apify data
- [ ] Download subtitle files (VTT/SRT format)
- [ ] Parse subtitle files to plain text
- [ ] Update media_events.subtitle_text and subtitle_source
- [ ] Mark non-video media types as complete (skip gracefully)
- [ ] Track in processing_steps table

### Out-of-scope / Non-goals
- Whisper transcription (task 3.6)
- OCR text extraction (task 3.7)
- Auto-generated captions (rely on Apify-provided subtitles only)

## 2) System context

### Components touched
- **Lambda function**: `attic-subtitle-fetch`
- **DB tables**: `media_events`, `processing_steps`
- **Step Functions**: Invoked as Map state

### Invariants (must always be true)
- Non-video media types return immediately with empty subtitle
- Subtitle parsing handles malformed files gracefully
- subtitle_source accurately reflects data origin

from uuid import UUID

class MediaItemInput(BaseModel):

    # Subtitle URL from Apify enrichment (if available)

class SubtitleFetchInput(BaseModel):

### Lambda Output
```python
from pydantic import BaseModel
from uuid import UUID
from typing import Literal

class SubtitleResult(BaseModel):
    media_event_id: UUID
    status: Literal["fetched", "not_available", "skipped", "failed"]
    subtitle_source: Literal["apify", None] = None
    subtitle_length: int | None = None
    error_message: str | None = None

class SubtitleFetchOutput(BaseModel):
    upload_id: UUID
    items_with_subtitles: int
    items_without_subtitles: int
    items_skipped: int  # Non-video media types
    results: list[SubtitleResult]
```

### Status codes
- Lambda returns output dict or raises exception
- Partial failures included in output

### Auth requirements
- Lambda IAM role for database access
- No auth needed for subtitle download (public URLs)

## 4) Data model changes

### media_events updates
```sql
UPDATE media_events SET
    subtitle_text = $subtitle_text,
    subtitle_source = 'apify',  -- or NULL if not available
    processing_substate = 'subtitles_fetched',
    updated_at = NOW()
WHERE id = $media_event_id;
```

### processing_steps insert
```sql
INSERT INTO processing_steps (
    id, media_event_id, step_type, provider, status,
    started_at, finished_at, output_summary
) VALUES (
    $id, $media_event_id, 'SUBTITLE_FETCH', 'apify',
    $status, $started_at, $finished_at, $output_summary
)
ON CONFLICT (media_event_id, step_type, attempt) DO UPDATE SET
    status = EXCLUDED.status,
    finished_at = EXCLUDED.finished_at,
    output_summary = EXCLUDED.output_summary;
```

## 5) Workflow & state machine (if applicable)

### States
- This Lambda IS a state in the pipeline (FetchSubtitles Map state)

### Idempotency strategy
- Upsert operations for all database writes
- Same subtitle URL returns same content
- Non-video types always return "skipped" status

### Failure modes + user-facing behavior
- **Subtitle URL 404**: Mark as not_available, continue
- **Malformed subtitle file**: Log warning, mark as failed
- **Non-video media type**: Skip gracefully (not an error)
