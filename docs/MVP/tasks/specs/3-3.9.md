Lambda function `attic-embedding` generates 1536-dimensional vector embeddings from the fused text using OpenAI text-embedding-3-small, enabling semantic search capabilities.

## 3) API contracts (authoritative)

### Lambda Input (from Step Functions Map)
```python
from pydantic import BaseModel
from uuid import UUID

class MediaItemInput(BaseModel):
    media_event_id: UUID
    full_text: str | None

class EmbeddingInput(BaseModel):
    upload_id: UUID
    user_id: UUID
    execution_arn: str
    batch_index: int
    media_items: list[MediaItemInput]  # Up to 100 items per batch
```

### Lambda Output
```python
from pydantic import BaseModel
from uuid import UUID
from typing import Literal

class EmbeddingResult(BaseModel):
    media_event_id: UUID
    status: Literal["embedded", "skipped", "failed"]
    embedding_dimension: int | None = None
    token_count: int | None = None
    error_message: str | None = None

class EmbeddingOutput(BaseModel):
    upload_id: UUID
    batch_index: int
    items_embedded: int
    items_skipped: int  # Empty full_text
    items_failed: int
    total_tokens: int
    total_cost_usd: float
    results: list[EmbeddingResult]
```

### OpenAI Embeddings API
```python
# POST https://api.openai.com/v1/embeddings
{
    "model": "text-embedding-3-small",
    "input": ["text1", "text2", ...],  # Up to 100 texts
    "encoding_format": "float"
}

# Response
{
    "data": [
        {"embedding": [0.123, -0.456, ...], "index": 0},
        ...
    ],
    "usage": {"total_tokens": 1234}
}
```

### Status codes
- Lambda returns output dict or raises exception
- Partial failures included in output

### Auth requirements
- OpenAI API key in environment variable `OPENAI_API_KEY`
- Lambda IAM role for database access

## 4) Data model changes

### media_events updates
```sql
UPDATE media_events SET
    embedding_vector = $embedding_vector::vector(1536),
    processing_substate = 'embedded',
    updated_at = NOW()
WHERE id = $media_event_id;
```

### processing_steps insert
```sql
INSERT INTO processing_steps (
    id, media_event_id, step_type, provider, status,
    started_at, finished_at, cost_usd, output_summary
) VALUES (
    $id, $media_event_id, 'EMBEDDING', 'openai_text_embedding_3_small',
    $status, $started_at, $finished_at, $cost_usd, $output_summary
)
ON CONFLICT (media_event_id, step_type, attempt) DO UPDATE SET
    status = EXCLUDED.status,
    finished_at = EXCLUDED.finished_at,
    cost_usd = EXCLUDED.cost_usd,
    output_summary = EXCLUDED.output_summary;
```

## 5) Workflow & state machine (if applicable)

### States
- This Lambda IS a state in the pipeline (GenerateEmbeddings Map state)
- Receives batches of up to 100 media items

### Idempotency strategy
- Same full_text produces same embedding (deterministic)
- Upsert operations for database writes
- Processing tracked by media_event_id

### Failure modes + user-facing behavior
- **OpenAI rate limit**: Retry with exponential backoff
- **OpenAI API error**: Retry, then mark as failed
- **Empty full_text**: Skip (not an error), mark as skipped
- **Text too long**: Truncate to model's context window
