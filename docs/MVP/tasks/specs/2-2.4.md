# Task 2.4: TikTok Export Parser

## 0) Outcome

A robust parser exists that extracts liked and favorited video URLs/timestamps from TikTok data export ZIP files. The parser validates the export structure, handles edge cases gracefully, and returns structured data for pipeline processing.

- [ ] Return counts for scope selection UI

### Data Models

```python
# src/backend/app/schemas/tiktok_export.py
from pydantic import BaseModel, Field, HttpUrl
from datetime import datetime
from typing import Literal

class TikTokVideoReference(BaseModel):
    """A single video reference from the export."""
    url: str = Field(..., description="TikTok video URL")
    timestamp: datetime = Field(..., description="When the user interacted with the video")
    interaction_type: Literal["liked", "favorited"] = Field(..., description="Type of interaction")

class TikTokExportSummary(BaseModel):
    """Summary of parsed export for scope selection."""
    liked_count: int = Field(..., description="Number of liked videos")
    favorited_count: int = Field(..., description="Number of favorited videos")
    total_count: int = Field(..., description="Total unique videos")
    has_liked: bool = Field(..., description="Export contains liked videos")
    has_favorited: bool = Field(..., description="Export contains favorited videos")

class TikTokParsedExport(BaseModel):
    """Complete parsed export data."""
    summary: TikTokExportSummary
    liked_videos: list[TikTokVideoReference] = Field(default_factory=list)
    favorited_videos: list[TikTokVideoReference] = Field(default_factory=list)

class ParseError(BaseModel):
    """Structured parse error."""
    code: str = Field(..., description="Error code")
    message: str = Field(..., description="Human-readable error message")
    details: dict | None = Field(default=None, description="Additional context")
```

### Error Types

```python
class TikTokParseError(Exception):
    """Base exception for parser errors."""
    code: str
    message: str

class InvalidExportError(TikTokParseError):
    """Export structure doesn't match expected TikTok format."""
    code = "INVALID_EXPORT"

class EmptyExportError(TikTokParseError):
    """No videos found in the specified scope."""
    code = "EMPTY_EXPORT"

class ZipSecurityError(TikTokParseError):
    """ZIP file failed security checks (path traversal, etc.)."""
    code = "ZIP_SECURITY_ERROR"
```

## 6) Implementation plan (ordered)

1. **Create data models**
   - Define Pydantic models in `schemas/tiktok_export.py`
   - Include all error types

2. **Implement ZIP security checks**
   - Validate all paths are within extraction directory
   - Check for absolute paths in ZIP entries
   - Limit file sizes during extraction
   - Use `zipfile.Path` for safe access

3. **Implement structure validation**
   - Check for expected directory structure
   - Validate required files exist:
     - `Activity/Like List.json` or `Activity/Favorite Videos.json`
   - Fail fast if structure doesn't match

4. **Implement liked videos parser**
   - Parse `Activity/Like List.json`
   - Extract `LikeList` array
   - Map to `TikTokVideoReference` objects

5. **Implement favorited videos parser**
   - Parse `Activity/Favorite Videos.json`
   - Extract `FavoriteList` array
   - Map to `TikTokVideoReference` objects

6. **Implement summary function**
   - Quick counts without full extraction
   - Used for scope selection UI

7. **Add edge case handling**
   - Empty arrays
   - Missing optional fields
   - Malformed dates
   - Duplicate URLs between liked/favorited

8. **Write comprehensive tests**
   - Use test fixtures from Dev Guide
   - Test all edge cases
   - Test security checks
