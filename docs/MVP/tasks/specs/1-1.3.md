# Task 1.3: Backend Auth Middleware

## 0) Outcome

The FastAPI backend validates Supabase JWTs on protected endpoints and derives `user_id` from the token. Endpoints correctly reject requests with invalid/missing tokens and provide the authenticated user's ID to route handlers.

### Auth Dependency Return Type

```python
from pydantic import BaseModel
from uuid import UUID

class AuthenticatedUser(BaseModel):
    """User info extracted from validated JWT."""
    id: UUID
    email: str | None = None
    # Note: email may not always be present in token

# Usage in route:
@router.get("/protected")
async def protected_route(user: AuthenticatedUser = Depends(get_current_user)):
    return {"user_id": user.id}
```

### Status codes

- `401 Unauthorized` - Missing, invalid, or expired token

N/A - Not a workflow task.

### Auth Validation Flow
```
1. Request arrives with Authorization header
2. Extract Bearer token from header
3. Decode JWT header (no verification) to get algorithm
4. Verify JWT signature using Supabase JWT secret
5. Validate claims:
   - iss (issuer): must match Supabase URL
   - aud (audience): must be "authenticated"
   - exp (expiry): must be in future
   - sub (subject): becomes user_id
6. Return AuthenticatedUser to route handler
```
