## 3) API contracts (authoritative)

### Page Flow States

```typescript
// src/frontend/hooks/useUploadFlow.ts
export type UploadFlowStep =
  | 'instructions'  // Showing export guide
  | 'uploading'     // File upload in progress
  | 'validating'    // Validation in progress
  | 'invalid'       // Validation failed
  | 'scope'         // Scope selection
  | 'consent'       // Consent modal open
  | 'complete';     // Redirecting to processing

export interface UploadFlowState {
  step: UploadFlowStep;
  uploadId: string | null;
  filename: string | null;
  likedCount: number;
  favoritedCount: number;
  selectedScope: Scope | null;
  totalItems: number;
  tierLimit: number;
  withinLimit: boolean;
  estimatedMinutes: number;
  error: UploadError | null;
}

export interface UploadFlowActions {
  startUpload: () => void;
  onUploadComplete: (result: UploadResult) => void;
  onValidationComplete: (result: ValidationResult) => void;
  selectScope: (scope: Scope) => void;
  confirmScope: () => void;
  giveConsent: () => void;
  cancelConsent: () => void;
  retry: () => void;
  reset: () => void;
}
```

## 5) Workflow & state machine

### Upload Flow Steps

```
┌─────────────────┐
│  instructions   │ ← Initial state, showing export guide
└────────┬────────┘
         │ User drops/selects file
         ▼
┌─────────────────┐
│   uploading     │ ← Uppy upload in progress
└────────┬────────┘
         │ Upload complete
         ▼
┌─────────────────┐
│   validating    │ ← Calling validate endpoint
└────────┬────────┘
         │
    ┌────┴────┐
    │         │
    ▼         ▼
┌───────┐  ┌─────────────────┐
│invalid│  │      scope      │ ← Showing scope selector
└───┬───┘  └────────┬────────┘
    │               │ User confirms scope
    │               ▼
    │      ┌─────────────────┐
    │      │    consent      │ ← Consent modal open
    │      └────────┬────────┘
    │               │ User consents
    │               ▼
    │      ┌─────────────────┐
    │      │    complete     │ ← Redirect to /processing/{id}
    │      └─────────────────┘
    │
    └──────► Can retry from here
```

### Error Recovery
- `invalid` state: Can retry with new file
- Network errors: Can retry current step
- Tier limit exceeded: Show upgrade prompt, can change scope
