## 6) Implementation plan (ordered)

1. Create `docker-compose.yml` with services:
   ```yaml
   services:
     localstack:
       image: localstack/localstack:latest
       ports:
         - "4566:4566"
       environment:
         - SERVICES=stepfunctions,lambda,sqs,s3,iam,logs
         - DEBUG=1
       volumes:
         - "./.docker/localstack:/etc/localstack/init/ready.d"
         - "/var/run/docker.sock:/var/run/docker.sock"

     backend:
       build:
         context: .
         dockerfile: .docker/backend/Dockerfile.dev
       ports:
         - "8000:8000"
       volumes:
         - "./src/backend:/app"
       environment:
         - DATABASE_URL=postgresql://postgres:postgres@host.docker.internal:54322/postgres
         - AWS_ENDPOINT_URL=http://localstack:4566
       depends_on:
         - localstack
   ```

2. Create `.docker/localstack/init-aws.sh`:
   ```bash
   #!/bin/bash
   # Create S3 bucket
   awslocal s3 mb s3://attic-temp-media

   # Create SQS queue
   awslocal sqs create-queue --queue-name attic-upload-queue

   # Deploy Step Functions (from SAM template)
   # Note: LocalStack supports SAM deployment
   ```

3. Create `.docker/backend/Dockerfile.dev`:
   ```dockerfile
   FROM python:3.12-slim
   WORKDIR /app
   COPY pyproject.toml .
   RUN pip install -e ".[dev]"
   CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--reload"]
   ```

4. Create `scripts/dev-start.sh`:
   ```bash
   #!/bin/bash
   # Start Supabase
   supabase start

   # Start Docker services
   docker-compose up -d

   # Start frontend (in separate terminal or tmux)
   cd src/frontend && npm run dev &

   echo "Services started:"
   echo "- Frontend: http://localhost:3000"
   echo "- Backend: http://localhost:8000"
   echo "- Supabase Studio: http://localhost:54323"
   ```

5. Create `scripts/dev-stop.sh`:
   ```bash
   #!/bin/bash
   docker-compose down
   supabase stop
   ```

6. Create `scripts/dev-reset.sh`:
   ```bash
   #!/bin/bash
   docker-compose down -v
   supabase db reset
   ./scripts/seed-db.sh
   ```

7. Create `scripts/seed-db.sh`:
   ```bash
   #!/bin/bash
   # Insert test user
   # Insert sample upload
   # Insert sample media events
   psql $DATABASE_URL -f scripts/seed.sql
   ```

8. Create `docker-compose.override.yml` for local tweaks
9. Document setup in `docs/setup/local-dev.md`
10. Test full stack startup and verify all services accessible
