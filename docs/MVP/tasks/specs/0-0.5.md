## 5) Workflow & state machine

### States (from PRD)
```
1. ParseExport - Extract URLs from ZIP
2. EnrichBatch - Map state for Apify calls (batched, 50 URLs)
3. ProcessVideos - Map state for per-video processing
   3a. DownloadMedia
   3b. FetchSubtitles
   3c. TranscribeAudio (conditional)
   3d. AnalyzeVision
   3e. GenerateEmbedding
4. TextFusion - Combine text fields
5. DerivedFields - Compute engagement metrics
6. UpdateSearchIndex - Update indexes
7. FinalizeUpload - Mark complete, notify
```

### State Machine Definition (ASL)
```json
{
  "Comment": "Attic Video Processing Pipeline",
  "StartAt": "ParseExport",
  "States": {
    "ParseExport": {
      "Type": "Task",
      "Resource": "${ParseExportFunction.Arn}",
      "Next": "EnrichBatch",
      "Retry": [{"ErrorEquals": ["States.ALL"], "MaxAttempts": 3, "BackoffRate": 2}],
      "Catch": [{"ErrorEquals": ["States.ALL"], "Next": "HandleError"}]
    },
    "EnrichBatch": {
      "Type": "Map",
      "ItemsPath": "$.batches",
      "MaxConcurrency": 10,
      "Iterator": {
        "StartAt": "CallApify",
        "States": {
          "CallApify": {
            "Type": "Task",
            "Resource": "${ApifyEnrichFunction.Arn}",
            "End": true,
            "Retry": [{"ErrorEquals": ["States.ALL"], "MaxAttempts": 3, "BackoffRate": 2}]
          }
        }
      },
      "Next": "ProcessVideos"
    },
    "ProcessVideos": {
      "Type": "Map",
      "ItemsPath": "$.videos",
      "MaxConcurrency": 5,
      "Iterator": {
        "StartAt": "DownloadMedia",
        "States": {
          "DownloadMedia": {"Type": "Task", "Resource": "${MediaDownloadFunction.Arn}", "Next": "FetchSubtitles"},
          "FetchSubtitles": {"Type": "Task", "Resource": "${SubtitleFetchFunction.Arn}", "Next": "CheckSubtitles"},
          "CheckSubtitles": {
            "Type": "Choice",
            "Choices": [{"Variable": "$.has_subtitles", "BooleanEquals": false, "Next": "TranscribeAudio"}],
            "Default": "AnalyzeVision"
          },
          "TranscribeAudio": {"Type": "Task", "Resource": "${WhisperTranscribeFunction.Arn}", "Next": "AnalyzeVision"},
          "AnalyzeVision": {"Type": "Task", "Resource": "${VisionAnalysisFunction.Arn}", "Next": "GenerateEmbedding"},
          "GenerateEmbedding": {"Type": "Task", "Resource": "${EmbeddingFunction.Arn}", "End": true}
        }
      },
      "Next": "TextFusion"
    },
    "TextFusion": {"Type": "Task", "Resource": "${TextFusionFunction.Arn}", "Next": "DerivedFields"},
    "DerivedFields": {"Type": "Task", "Resource": "${DerivedFieldsFunction.Arn}", "Next": "UpdateSearchIndex"},
    "UpdateSearchIndex": {"Type": "Task", "Resource": "${SearchIndexFunction.Arn}", "Next": "FinalizeUpload"},
    "FinalizeUpload": {"Type": "Task", "Resource": "${FinalizeFunction.Arn}", "End": true},
    "HandleError": {"Type": "Task", "Resource": "${ErrorHandlerFunction.Arn}", "End": true}
  }
}
```

### Retry policy + timeouts
- Default retry: 3 attempts with exponential backoff (2x)
- Lambda timeout: 15 minutes (max for Step Functions integration)
- State machine timeout: 1 hour per execution

### Idempotency strategy
Documented requirement for all Lambda implementations:
- Use deterministic IDs based on `upload_id + video_url`
- Use upserts for all database writes
- Check processing_state before re-processing

### Failure modes + user-facing behavior
- Single video failure: Continue processing others, mark video as failed
- Batch failure: Retry batch, then mark affected videos as failed
- Total failure: Mark upload as failed, notify user
