# Task 3.2: Lambda: PARSE_EXPORT

## 0) Outcome

Lambda function `attic-parse-export` extracts URLs from the uploaded TikTok export ZIP and creates `media_event` rows in the database with initial `processing_state: pending`.

## 1) Scope

### In-scope
- [ ] Lambda function that downloads ZIP from Supabase Storage
- [ ] Parse TikTok export JSON structure (Like List.json, Favorite Videos.json)
- [ ] Extract video URLs based on scope (liked/favorited/both)
- [ ] Detect media type from URL/structure (video, image, slideshow)
- [ ] Create `media_event` rows with deterministic IDs (user_id + platform + platform_id)
- [ ] Create/update `upload_pipeline_runs` record
- [ ] Delete raw ZIP after successful parsing
- [ ] Return list of media_event IDs for next pipeline step

### Out-of-scope / Non-goals
- ZIP validation (handled by task 2.5)
- Consent verification (handled by upload flow)
- Metadata enrichment (task 3.3)

## 2) System context

### Components touched
- **Lambda function**: `attic-parse-export`
- **Supabase Storage**: Read from `uploads` bucket
- **DB tables**: `uploads`, `upload_pipeline_runs`, `media_events`
- **Step Functions**: Invoked as first step in pipeline

### Invariants (must always be true)
- Raw ZIP must be deleted even on error paths (compensating cleanup)
- media_event IDs must be deterministic (idempotent on retry)
- Only whitelisted files are parsed (Like List.json, Favorite Videos.json)
- All media_events must have valid user_id and upload_id

### media_events inserts

```python
# Deterministic ID generation for idempotency

# Insert with upsert
INSERT INTO media_events (
    id, user_id, upload_id, platform, platform_id, canonical_url,
    interaction_type, interaction_at, media_type, processing_state
) VALUES (...)
ON CONFLICT (user_id, platform, platform_id) DO UPDATE SET
    upload_id = EXCLUDED.upload_id,
    interaction_type = EXCLUDED.interaction_type,
    updated_at = NOW();
```

### upload_pipeline_runs insert
```python
INSERT INTO upload_pipeline_runs (
    id, upload_id, user_id, status, started_at, total_videos
) VALUES (...)
ON CONFLICT (upload_id) DO UPDATE SET
    status = 'processing',
    started_at = NOW(),
    total_videos = EXCLUDED.total_videos;
```

## 5) Workflow & state machine (if applicable)

### States
- This Lambda IS a state in the pipeline (ParseExport state)

### Idempotency strategy
- Deterministic media_event IDs using uuid5(user_id:platform:platform_id)
- Upsert operations for all database writes
- Idempotent ZIP deletion (no-op if already deleted)

### Failure modes + user-facing behavior
- **Invalid ZIP structure**: Raise exception, Step Functions catches, upload marked failed
- **Missing expected files**: Raise exception with clear error message
- **Database error**: Retry with backoff (Step Functions retry policy)
- **Storage error**: Retry with backoff
