## 6) Implementation plan (ordered)

1. Install Supabase CLI: `brew install supabase/tap/supabase`
2. Create Supabase project via dashboard (or `supabase projects create`)
3. Initialize local Supabase: `supabase init`
4. Configure `supabase/config.toml` with project settings
5. Start local Supabase: `supabase start`
6. Enable pgvector extension via SQL editor or migration:
   ```sql
   CREATE EXTENSION IF NOT EXISTS vector;
   ```
7. Create Storage bucket 'uploads' via dashboard
8. Create `src/backend/app/db/session.py` with async SQLAlchemy engine:
