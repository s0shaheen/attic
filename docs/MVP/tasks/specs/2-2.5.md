# Task 2.5: Upload Validation & Error Handling

## 0) Outcome

```python
# src/backend/app/schemas/uploads.py
from pydantic import BaseModel, Field
from uuid import UUID
from enum import Enum

class ValidationErrorCode(str, Enum):
    INVALID_FILE = "INVALID_FILE"  # Not a valid ZIP
    INVALID_EXPORT = "INVALID_EXPORT"  # ZIP doesn't contain TikTok export
    EMPTY_EXPORT = "EMPTY_EXPORT"  # No liked/favorited videos
    FILE_TOO_LARGE = "FILE_TOO_LARGE"  # Exceeds 500MB
    FILE_CORRUPTED = "FILE_CORRUPTED"  # ZIP is corrupted
    UNSUPPORTED_FORMAT = "UNSUPPORTED_FORMAT"  # Not JSON format export

class ValidationResult(BaseModel):
    """Result of file validation."""
    valid: bool = Field(..., description="Whether the file passed validation")
    error_code: ValidationErrorCode | None = Field(
        default=None,
        description="Error code if validation failed"
    )
    error_message: str | None = Field(
        default=None,
        description="Human-readable error message"
    )
    liked_count: int | None = Field(
        default=None,
        description="Number of liked videos found (if valid)"
    )
    favorited_count: int | None = Field(
        default=None,
        description="Number of favorited videos found (if valid)"
    )
    file_hash: str | None = Field(
        default=None,
        description="SHA256 hash for debugging (not content)"
    )

class ValidateUploadRequest(BaseModel):
    """Request to validate an uploaded file."""
    # No body - upload_id comes from path

class ValidateUploadResponse(BaseModel):
    """Response from validation endpoint."""
    upload_id: UUID
    validation: ValidationResult
```

### Status codes
- `200 OK` - Validation complete (check `valid` field for result)
- `401 Unauthorized` - Missing or invalid auth
- `403 Forbidden` - Upload belongs to different user
- `404 Not Found` - Upload ID not found
- `500 Internal Server Error` - Validation failed unexpectedly

### Auth requirements
- Required: Supabase JWT
- User must own the upload (enforced via RLS + check)

## 5) Workflow & state machine

### Validation States
- `pending` → `validating`: When validate endpoint called
- `validating` → `validated`: Validation passed
- `validating` → `invalid`: Validation failed

### Validation Flow
1. File uploaded to Storage (Task 2.3)
2. Frontend calls `POST /api/uploads/{id}/validate`
3. Backend downloads file from Storage
4. Backend validates ZIP structure
5. Backend parses export summary (using Task 2.4 parser)
6. Backend returns validation result
7. Frontend shows counts or error
8. If valid, proceed to scope selection
