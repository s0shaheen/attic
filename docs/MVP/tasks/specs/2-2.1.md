### Storage Path Convention
```
tiktok-exports/{user_id}/{upload_id}.zip
```

Where:
- `user_id` is the authenticated user's UUID from Supabase Auth
- `upload_id` is a UUID generated when the upload is initiated

### Supabase Storage RLS Policy Reference
```sql
-- Read policy: users can only read their own files
CREATE POLICY "Users can read own files"
ON storage.objects FOR SELECT
USING (
  bucket_id = 'tiktok-exports'
  AND auth.uid()::text = (storage.foldername(name))[1]
);

-- Insert policy: users can only upload to their own folder
CREATE POLICY "Users can upload own files"
ON storage.objects FOR INSERT
WITH CHECK (
  bucket_id = 'tiktok-exports'
  AND auth.uid()::text = (storage.foldername(name))[1]
);

-- Delete policy: users can delete their own files
CREATE POLICY "Users can delete own files"
ON storage.objects FOR DELETE
USING (
  bucket_id = 'tiktok-exports'
  AND auth.uid()::text = (storage.foldername(name))[1]
);
```
