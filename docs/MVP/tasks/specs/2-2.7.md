```python
# src/backend/app/schemas/uploads.py
from pydantic import BaseModel, Field
from uuid import UUID
from datetime import datetime

CURRENT_CONSENT_VERSION = "1.0.0"

class ConsentRequest(BaseModel):
    """Request to record consent."""
    consent_given: bool = Field(
        ...,
        description="User explicitly consented"
    )
    consent_version: str = Field(
        default=CURRENT_CONSENT_VERSION,
        description="Version of consent text shown"
    )

class ConsentResponse(BaseModel):
    """Response after consent recorded."""
    upload_id: UUID
    consent_given: bool
    consent_version: str
    consent_at: datetime
    ready_to_process: bool = Field(
        ...,
        description="Whether processing can now start"
    )
```

### Status codes
- `200 OK` - Consent recorded successfully
- `400 Bad Request` - consent_given is false (decline handled client-side)
- `401 Unauthorized` - Missing or invalid auth
- `403 Forbidden` - Upload belongs to different user
- `404 Not Found` - Upload ID not found
- `409 Conflict` - Consent already recorded or upload not ready
- `422 Unprocessable Entity` - Scope not selected yet

### Auth requirements
- Required: Supabase JWT
- User must own the upload

## 4) Data model changes

### Add consent fields to uploads table

```sql
-- Migration: Add consent fields
ALTER TABLE uploads
ADD COLUMN IF NOT EXISTS consent_given BOOLEAN DEFAULT FALSE,
ADD COLUMN IF NOT EXISTS consent_version VARCHAR(20),
ADD COLUMN IF NOT EXISTS consent_at TIMESTAMPTZ;

-- Constraint: consent_version required if consent_given
ALTER TABLE uploads
ADD CONSTRAINT consent_version_required
CHECK (consent_given = FALSE OR consent_version IS NOT NULL);
```

### Status Updates
- `scope_selected` → `consented`: When consent is recorded
- `consented` → `processing`: When pipeline starts (Epic 3)

## 5) Workflow & state machine

### Consent Flow
1. Scope selected (status = "scope_selected")
2. Consent modal opens
3. User reads disclosures
4. User clicks "I Understand, Continue"
5. Frontend calls `POST /api/uploads/{id}/consent`
6. Backend records consent with version and timestamp
7. Status becomes "consented"
8. Processing can begin

### Cancel Flow
1. User clicks "Cancel"
2. Modal closes
3. User returns to scope selection
4. Can change scope and try again
