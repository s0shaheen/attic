## 5) Workflow & state machine (if applicable)

### States
1. **ParseExport**: Extract URLs from ZIP, create media_event rows
2. **EnrichBatch**: Map state - Apify metadata enrichment (batched 50/call)
3. **DownloadMedia**: Map state - Download videos/images to S3 temp
4. **FetchSubtitles**: Map state - Get subtitles if available
5. **TranscribeAudio**: Map state - Whisper transcription (skip for non-video)
6. **AnalyzeVision**: Map state - GPT-4 Vision tagging (batched 5/call)
7. **FuseText**: Map state - Combine all text fields
8. **GenerateEmbeddings**: Map state - OpenAI embeddings (batched 100/call)
9. **ComputeDerivedFields**: Map state - Calculate engagement_rate, etc.
10. **UpdateSearchIndex**: Map state - Update FTS + vector indexes
11. **FinalizeUpload**: Update upload status, send notification

### Transitions
```
ParseExport → EnrichBatch → DownloadMedia → FetchSubtitles → TranscribeAudio
→ AnalyzeVision → FuseText → GenerateEmbeddings → ComputeDerivedFields
→ UpdateSearchIndex → FinalizeUpload
```

### Retry policy + timeouts
| State | Timeout | Max Retries | Backoff |
|-------|---------|-------------|---------|
| ParseExport | 5 min | 3 | 2x |
| EnrichBatch | 30 min | 3 | 2x |
| DownloadMedia | 60 min | 3 | 2x |
| FetchSubtitles | 10 min | 3 | 2x |
| TranscribeAudio | 30 min | 3 | 2x |
| AnalyzeVision | 60 min | 3 | 2x |
| FuseText | 10 min | 3 | 2x |
| GenerateEmbeddings | 30 min | 3 | 2x |
| ComputeDerivedFields | 10 min | 3 | 2x |
| UpdateSearchIndex | 15 min | 3 | 2x |
| FinalizeUpload | 2 min | 3 | 2x |

### Idempotency strategy
- Each Lambda receives `upload_id` and `execution_id` for idempotent operations
- Lambdas use upserts with deterministic IDs
- State machine input includes `idempotency_key` derived from upload_id

### Failure modes + user-facing behavior
- **Single item failure**: Logged, processing continues (partial success)
- **Batch failure**: Retry with backoff, then mark batch as failed
- **Step timeout**: Catch block moves to error state, marks upload as failed
- **All failures**: `upload_pipeline_runs.status = 'failed'`, user sees error message
