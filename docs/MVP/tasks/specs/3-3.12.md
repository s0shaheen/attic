## 3) API contracts (authoritative)

### SQS Message Format
```python
from pydantic import BaseModel
from uuid import UUID

class UploadTriggerMessage(BaseModel):
    upload_id: UUID
    user_id: UUID
    storage_path: str  # "uploads/{user_id}/{upload_id}/export.zip"
    scope: str  # "liked" | "favorited" | "both"
    tier: str  # "free" | "explorer" | "expert" | "pioneer"
```

### Lambda Input (from SQS)
```json
{
  "Records": [
    {
      "messageId": "...",
      "body": "{\"upload_id\": \"...\", ...}",
      "attributes": { ... }
    }
  ]
}
```

### Lambda Output
```python
from pydantic import BaseModel
from uuid import UUID

class TriggerResult(BaseModel):
    upload_id: UUID
    execution_arn: str | None
    status: str  # "started" | "skipped" | "failed"
    error_message: str | None = None
```

### Step Functions Start Execution
```python
import boto3

sfn = boto3.client('stepfunctions')
response = sfn.start_execution(
    stateMachineArn='arn:aws:states:...:attic-media-processing-pipeline',
    name=f'upload-{upload_id}',  # Deterministic name for idempotency
    input=json.dumps({
        'upload_id': str(upload_id),
        'user_id': str(user_id),
        'storage_path': storage_path,
        'scope': scope,
        'tier': tier
    })
)
```

### Status codes
- Lambda returns batch item failures for SQS retry
- Step Functions returns execution ARN on success

### Auth requirements
- Lambda IAM role with SQS receive, Step Functions start execution
- Database credentials for upload validation


## 5) Workflow & state machine (if applicable)

N/A - This task creates the trigger mechanism, not a workflow state.

### Idempotency strategy
- Step Functions execution name = `upload-{upload_id}` (deterministic)
- Starting execution with same name returns existing execution (idempotent)
- SQS message deduplication via content-based deduplication

### Failure modes + user-facing behavior
- **Upload not found**: Log warning, don't start pipeline
- **Upload already processing**: Skip (idempotent)
- **Step Functions error**: Message goes to DLQ, alert triggered
- **Database error**: Retry via SQS redelivery
