## 6) Implementation plan (ordered)

1. Create `src/frontend/` directory
2. Initialize Next.js 14 with App Router:
   ```bash
   npx create-next-app@14 . --typescript --tailwind --eslint --app --src-dir=false
   ```
3. Configure TypeScript strict mode in `tsconfig.json`
4. Set up Tailwind with warm minimal theme (cream backgrounds, rounded corners)
5. Initialize shadcn/ui:
   ```bash
   npx shadcn@latest init
   npx shadcn@latest add button card input
   ```
6. Install TanStack Query: `npm install @tanstack/react-query`
7. Install React Hook Form with Zod: `npm install react-hook-form @hookform/resolvers zod`
8. Create `lib/query-client.ts` with QueryClient configuration
9. Create `components/providers.tsx` with QueryClientProvider
10. Update `app/layout.tsx` to use Providers wrapper
11. Create placeholder `app/page.tsx` with Attic branding
12. Configure ESLint rules for React/Next.js
13. Configure Prettier for consistent formatting
14. Verify: `npm run build` succeeds
15. Verify: `npm run lint` passes
16. Verify: `npm run typecheck` passes
